# PDF智能问答功能 - 快速开始

## 访问功能

部署网站后，访问 `/pdf-qa` 路径即可使用PDF智能问答功能。

例如：`https://yourdomain.com/pdf-qa`

## 快速使用

### 1. 上传PDF

- 点击左侧面板的"上传"按钮
- 选择PDF文件（最大10MB）
- 等待处理完成

### 2. 开始提问

- 在左侧选择已上传的PDF文档
- 在输入框中输入问题
- 按Enter或点击"发送"获取答案

### 3. 管理文档

- 点击文档卡片切换不同PDF
- 点击"删除"按钮移除不需要的文档

## 特性说明

- ✅ **持久化存储**：所有数据保存在浏览器IndexedDB中，永久保留
- ✅ **离线可用**：无需网络连接即可查询已上传的PDF
- ✅ **隐私安全**：所有数据仅存储在本地，不上传服务器
- ✅ **多文档支持**：同时管理多个PDF，独立问答会话
- ✅ **历史记录**：自动保存所有对话，随时回顾

## 技术特点

- 基于PDF.js实现浏览器端PDF文本提取
- 使用IndexedDB提供长期记忆能力
- 关键词搜索算法快速定位相关内容
- 响应式设计，支持移动端访问

## 注意事项

1. 文件大小限制为10MB
2. 仅支持文本型PDF（非扫描图片）
3. 清除浏览器数据会删除所有PDF和对话记录
4. 不同浏览器的数据独立存储

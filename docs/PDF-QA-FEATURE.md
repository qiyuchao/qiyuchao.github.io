# PDF智能问答功能文档

## 功能概述

PDF智能问答系统是一个基于浏览器的智能文档处理和问答工具。它允许用户上传PDF文档，系统会自动提取文档内容并存储在浏览器本地，用户可以针对文档内容进行智能问答。

## 主要特性

### 1. 长期记忆能力

- 使用 IndexedDB 存储PDF内容和对话历史
- 所有数据保存在浏览器本地，不会丢失
- 即使关闭浏览器后重新打开，之前上传的PDF和对话记录仍然保留

### 2. PDF文档处理

- 支持上传标准PDF文件（最大10MB）
- 使用 PDF.js 库自动提取文本内容
- 智能文本分块，便于搜索和检索

### 3. 智能问答

- 基于关键词搜索的智能匹配算法
- 返回PDF中与问题最相关的内容片段
- 保存所有问答历史，方便查阅

### 4. 多文档管理

- 支持同时管理多个PDF文档
- 每个文档独立的问答会话
- 轻松切换不同文档进行问答

## 使用方法

### 上传PDF文档

1. 访问网站的"PDF问答"页面
2. 点击左侧面板的"上传"按钮
3. 选择要上传的PDF文件（需要是有效的PDF格式，不超过10MB）
4. 等待系统处理完成

### 提问

1. 在左侧列表中选择一个已上传的PDF文档
2. 在右侧聊天界面的输入框中输入您的问题
3. 点击"发送"按钮或按Enter键提交问题
4. 系统会搜索PDF内容并返回相关答案

### 管理文档

- **查看文档**：点击左侧列表中的文档名称即可切换到该文档
- **删除文档**：点击文档卡片上的"删除"按钮，确认后即可删除文档及其所有对话记录

## 技术实现

### 前端技术栈

- **Astro**: 静态站点生成框架
- **React**: UI组件库
- **Framer Motion**: 动画效果
- **PDF.js**: PDF文档解析
- **IndexedDB (idb)**: 本地数据库存储

## 限制和注意事项

1. **文件大小限制**：单个PDF文件最大10MB
2. **浏览器存储**：数据存储在浏览器本地，清除浏览器数据会删除所有内容
3. **文本提取**：仅支持包含可提取文本的PDF，扫描版PDF可能无法正常工作
4. **安全性**：所有数据仅存储在本地浏览器中，不会上传到服务器
